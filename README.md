# DropZone — Community Tournament Series Demo

Responsive front-end concept for Free Fire MAX tournament organisers.

## Includes
- Tournament listings and sample prize pool/slots
- Event registration form
- Match schedule and sample leaderboard
- Organiser dashboard with registration status controls
- Responsive layout for desktop and mobile

## Demo limits
This is a portfolio/demo prototype only. All tournament names, prize pools, slots, teams and scores are illustrative. Registrations are held in the current browser page state; they are not saved to a database, sent to an organiser or connected to payments, room ID/password dispatch, WhatsApp, Discord, or live match data. A production implementation needs backend storage, organiser authentication, validation, and notification integrations.
